One-word entry for [make.fun's "One Word, One Username, One Reward" bounty](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae): our own make.fun username and nothing else, at most 30 characters.

## How it works

`main.py` writes the username to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, no model calls — the same word every run.

```text
hazel-fox-13-7204
```
